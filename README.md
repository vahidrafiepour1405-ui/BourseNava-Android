# بورس‌نوا (BourseNava)

پروژه مستقل اندروید برای نمایش داده‌های بورس ایران با منبع و زمان دریافت. این نسخه هنوز نیازمند استقرار بک‌اند و اعتبارسنجی اتصال زنده TSETMC است؛ تا زمان تأیید داده، سیگنال معاملاتی قطعی ارائه نمی‌کند.

## ساخت APK
GitHub Actions را از زبانه Actions اجرا کنید؛ فایل خروجی با نام `BourseNava-debug-apk` به‌صورت artifact ذخیره می‌شود.

## بک‌اند
پوشه `backend` سرویس FastAPI را دارد. آدرس API اپ باید پس از استقرار، در `MainActivity.kt` تنظیم شود.
